#  Контроль дебиторской задолженности и платёжной дисциплины клиентов

## В разработке

Контроль дебиторской задолженности и платёжной дисциплины клиентов
Суть того, что я хочу получить по итогу: разработать инструмент, позволяющий контролировать задолженность клиентов, анализировать просроченные платежи и оценивать платёжную дисциплину покупателей.

Представьте ситуацию для примера:

В компании есть 200 клиентов. Некоторые покупают товары с отсрочкой платежа. Одни оплачивают вовремя, другие задерживают оплату на несколько дней, а третьи уже несколько месяцев не погашают задолженность.

Руководителю отдела продаж нужно понимать:
1) Сколько денег должны клиенты компании?
2) Какие клиенты имеют просроченную задолженность?
3) Сколько дней длится просрочка?
4) Какой менеджер отвечает за проблемного клиента?
5) Какие клиенты создают наибольшую дебиторскую задолженность?
6) Как меняется задолженность с течением времени?

Оператору 1С нужно иметь возможность найти конкретного клиента и разобраться, из каких операций образовалась задолженность.

А мой отчёт должен помогать решать все эти задачи.
