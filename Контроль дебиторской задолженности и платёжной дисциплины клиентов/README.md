# Контроль дебиторской задолженности и платёжной дисциплины клиентов

## В разработке

**Цель проекта:** разработать инструмент, позволяющий контролировать задолженность клиентов, анализировать просроченные платежи и оценивать платёжную дисциплину покупателей.

### Пример ситуации

В компании есть 200 клиентов. Некоторые покупают товары с отсрочкой платежа:
- Одни оплачивают вовремя;
- Другие задерживают оплату на несколько дней;
- Третьи уже несколько месяцев не погашают задолженность.

### Задачи для руководителя отдела продаж

Руководителю необходимо понимать:
1. Сколько денег должны клиенты компании?
2. Какие клиенты имеют просроченную задолженность?
3. Сколько дней длится просрочка?
4. Какой менеджер отвечает за проблемного клиента?
5. Какие клиенты создают наибольшую дебиторскую задолженность?
6. Как меняется задолженность с течением времени?

### Задачи для оператора 1С

Оператор должен иметь возможность найти конкретного клиента и разобраться, из каких операций образовалась задолженность.

Отчёт должен помогать решать все эти задачи.
